# Evidence handling and reproduction

Scope: deployed baseline `ccb8fb2c96c85dc1760fca0a407627aef8e6728e`, 6 September 2026.
All database results here are aggregates or schema metadata. No row-level personal
information, credentials, production dumps or private uploads are included.

- `schema-field-inventory.csv`: every live table/column/type, including historical tables.
- `production-aggregates.json`: table counts, scheduled task outcomes and legacy page-view totals.
- `metrics.json`: brand-scoped event counts, MFA enrolment count and saved/claim counts.
- `provenance.json`: stored source/licence counts, active listings, brand and email states.
- `snapshot.php`, `metrics.php`, `provenance.php`: read-only transaction collectors.
  Pipe their source into PHP in the existing app container working directory;
  do not publish these scripts as HTTP endpoints or print environment values.
- `restore.sh`, `restore-evidence.txt`: checksum-verified isolated local database
  restoration; run only on the documented host with the specified backup present.
  It refuses to overwrite a same-named container. It creates a network-isolated,
  memory-limited temporary container and removes that container/volume on exit.
  No download of production data is required. This is not off-site recovery.
- `npm-licences.csv`: lock-file package metadata; PHP register is in acquisition/DEPENDENCIES.md.

The first collector's timestamp was emitted by the app's PHP environment; retain
its supplied offset and do not infer clock synchronisation from the field name.
Snapshots are separate transactions and may differ as live imports progress.

Browser evidence is generated by the maintained Playwright suite at desktop
1440x900 and mobile 390x844. Set `ASSIST_SALE_LIVE=1`,
`PLAYWRIGHT_BASE_URL=https://vanassist.com.au` and `PLAYWRIGHT_SCREENSHOT_DIR`.
`ASSIST_CANDIDATE_WORKER=1` substitutes the candidate worker only in the test
browser; this MUST be labelled overlay evidence, never a production deployment.
Run without that variable after the approved candidate is deployed.
